Technology

Core Model

핵심 모델

최신 Transformer 기반 DeBERTa-v3 모델을 적용하여 URL의 의미적 맥락과 숨은 위험 패턴을 정밀하게 학습하고, 지능화된 악성 URL을 높은 정확도로 탐지합니다.

How it Works

작동 원리

사용자가 입력한 URL을 토큰 단위로 분석하고, Transformer가 문맥적 특징을 추출하여 정상/악성을 실시간으로 분류합니다.

Tech Stack

기술 스택

모델 학습은 PyTorch와 Hugging Face 기반으로 진행되며, FastAPI와 React를 통해 웹 서비스화되었습니다.
